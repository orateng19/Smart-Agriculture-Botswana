About Smart Agriculture Botswana

Applying data analytics and machine learning to agricultural decision-support.

Who We Are

Smart Agriculture Botswana is an academic project focused on exploring how data analytics and machine learning can support agricultural decision-making in Botswana.

The proposed system uses agricultural and weather-related data to explore historical crop-yield patterns and provide estimated crop yields through a web-based interface.

Our Vision

To contribute to more informed and accessible agricultural decision-making through the responsible use of data and machine-learning technologies.

Our Mission

To develop a user-friendly decision-support prototype that presents agricultural data, estimates crop yields and communicates useful information for farming decisions.

Project Objectives

  1. Collect, clean and prepare relevant agricultural data.
  2. Conduct exploratory data analysis to identify patterns in crop yields and weather-related variables.
  3. Compare suitable machine-learning regression models using appropriate evaluation metrics.
  4. Develop and evaluate a selected crop-yield prediction model.
  5. Integrate the trained model into a website to make predictions accessible through a user interface.

How the System Works

1. Data Preparation

Agricultural data is cleaned and prepared for analysis and machine learning.

2. Model Development

Machine-learning models are trained and evaluated using suitable performance metrics.

3. Prediction

The website sends user inputs to the trained model and displays the estimated crop yield.

Technology Used

  • Python: data preparation and model development.
  • Pandas: agricultural dataset processing.
  • Scikit-learn: machine-learning model development.
  • HTML and CSS: website structure and design.
  • JavaScript: interactive website features.
  • Flask: connecting the website to the Python model.

Limitations

The reliability of the system depends on the quality, size and geographic coverage of the available datasets, as well as the performance of the trained model.

A limited number of Botswana-specific observations may affect how well model results generalise to different farming areas. Predictions should therefore be interpreted cautiously and should not replace expert agricultural advice.
